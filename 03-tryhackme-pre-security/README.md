## Overview

Foundational, hands-on training covering how computer systems, operating systems, networks, and the web actually work — plus an introduction to thinking like both an attacker and a defender. Completed as the practical groundwork underneath my forensics research (see the two case studies in this repository), giving me verified, lab-tested fundamentals rather than theory alone.

## Topics Covered

- **Computer Fundamentals** — client-server basics, virtualisation, cloud computing fundamentals
- **Operating Systems Basics** — Windows CLI basics, Linux CLI basics, OS security fundamentals
- **Software Basics** — data representation & encoding, intro scripting (Python, JavaScript), SQL basics
- **Network Fundamentals** — LAN basics, the OSI model, packets & frames
- **How the Web Works** — DNS in detail, HTTP in detail, website architecture
- **Attacks & Defenses** — the CIA triad, cryptography concepts, offensive vs. defensive security mindsets

## Why It Matters for SOC/DFIR Work

These fundamentals underpin the forensic work in this repository directly: OSI-model and packet-level networking knowledge supports network-based incident investigation, and Windows/Linux CLI fluency supports live-system triage during incident response — the same skill set a Tier-1 SOC Analyst uses daily.
